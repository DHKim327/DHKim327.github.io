Selected Research

Framework lead · First author

scUnify

A unified framework for training and inference across multiple single-cell foundation models. I led the framework design and implementation, including model adapters, downstream tasks, parameter-efficient fine-tuning, evaluation, and resource-aware execution.

Paper ↗ Code ↗ Docs ↗

Method lead · Co-first author

spHOT

A deep-learning framework for phenotype-associated regional detection in spatial transcriptomics. I developed the core method around spatial foundation-model embeddings, hierarchical domain trees, and teacher–student multiple-instance learning.

Paper ↗ Code ↗

Clinical data QC Agent Query → plan → execute → validate

Agent systems lead · Ongoing

QCAgent

A multi-agent framework for quality control in CDM and KR-CDI hospital-data integration. I am responsible for the agent layer: receiving queries through vLLM and backend services, orchestrating specialized agents with LangGraph, and connecting them to existing Airflow APIs.
